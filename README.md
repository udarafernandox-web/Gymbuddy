# Gym Buddy Android APK

This repository is a lightweight Capacitor 7 Android wrapper for **https://gymbuddypro.lovable.app**. It does not contain the Gym Buddy web source code, and requires a network connection. The live site must be published and accessible. Do not use the APK to evaluate unpublished changes.

## Build on GitHub

Open **Actions → Build Gym Buddy Android APK**. The workflow triggers when source files are pushed to main, and can also be run through **Run workflow**. Once the build succeeds, download **GymBuddy-debug-APK** from the workflow run's Artifacts area. Unzip it and install `app-debug.apk` on your Android phone (allow installation from this source if prompted).

This is a **debug-signed testing APK**, not a Play Store release. The APK is generated by GitHub Actions; no APK is committed to the repository.

## Local build

Install Node 22, JDK 21 and the Android SDK. Then run:

```sh
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

APK path: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Important limitations

- The app displays the **published** URL, which must be verified and online; custom domain changes require updating `capacitor.config.json` and the offline links.
- Email/password sign-in may work; Google OAuth inside embedded WebViews can be restricted and is not guaranteed.
- Deep-link password recovery and Android back navigation need device testing; this wrapper does not claim to solve them.
- Android default icon is used until branded assets are configured.
- This wrapper does not access or modify Gym Buddy's Supabase database.
